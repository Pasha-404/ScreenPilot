# ADR-0007: выпуск 0.1.0, runtime и hardening

- Статус: принято
- Дата: 2026-08-21

## Контекст

Этапы 8–9 требуют исключить параллельные экземпляры, предоставить логи и безопасную диагностику, а также собрать EXE для текущего пользователя без отдельной установки Java. Локальный runtime mpv не хранится в Git, но обязан быть проверен перед включением в пользовательскую сборку.

## Решение

1. Один экземпляр владеет file lock `%LOCALAPPDATA%\ScreenPilot\screenpilot.lock`. Не-владелец показывает `APP-001` и завершает работу до создания application service и любых Win32-операций.
2. Logback пишет INFO-логи в UTF-8 `%LOCALAPPDATA%\ScreenPilot\logs\screenpilot.log`, с ротацией по 5 МБ и пятью архивными файлами. На INFO записывается только имя видео, а не полный путь.
3. Кнопка «Копировать диагностику» формирует отчёт на `application-serial`: версия, ОС/Java, экраны и режимы, состояние сессии, последние 100 строк лога и найденные коды ошибок. Windows-пути и домашний каталог редактируются до передачи в clipboard.
4. `MpvPlayerAdapter` после каждого обычного `loadfile` явно задаёт `pause=false`. Это не полагается на неявное состояние `--keep-open=yes` после конца файла и устраняет ситуацию, в которой UI показывает «Пауза», но для старта нужно ещё раз нажать кнопку.
5. Решение resume принимается один раз для точной сохранённой записи. При выборе «С начала» запись удаляется; при выборе «Продолжить» её значение запоминается в процессе, чтобы не появлялся второй одинаковый диалог. После нового сохранения позиции вновь показывается актуальный выбор.
6. Gradle-задача `verifyMpvRuntime` сверяет хэши mpv, `d3dcompiler_43.dll` и `fonts.conf`. `packageAppImage` размещает их рядом с JAR в `app/mpv`; `ApplicationPaths` сначала ищет именно этот путь, затем development runtime. `packageInstaller` строит `jpackage --type exe --win-per-user-install` из app image.

## Последствия

- Конечному пользователю не нужна Java и не нужны права администратора.
- Публичный Git-репозиторий содержит только исходный код и сведения о runtime, но не его бинарники и не готовый EXE.
- Упакованное приложение проверено запуском без HDMI. Чистые install/update/uninstall и физические сценарии ТВ остаются отдельными ручными проверками.
